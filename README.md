# Projeto de Reconhecimento de Joias

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-brightgreen)](https://lucashx12.github.io/C-digo/)
[![Python](https://img.shields.io/badge/Python-3.14-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Um projeto web interativo para reconhecimento de joias usando inteligência artificial, desenvolvido com HTML, CSS e JavaScript. Inclui também uma coleção de scripts Python educacionais para demonstração de conceitos de programação.

## 📋 Descrição

Este projeto consiste em:
- **Site Web Principal**: Uma aplicação web que utiliza a câmera do dispositivo para reconhecimento de joias em tempo real
- **Scripts Python**: Exemplos educacionais incluindo cálculo de faturas, verificação de números primos e estatísticas básicas

O site está hospedado no GitHub Pages e pode ser acessado em: [https://lucashx12.github.io/C-digo/](https://lucashx12.github.io/C-digo/)

## ✨ Funcionalidades

### 🌐 Site Web
- **Reconhecimento de Joias**: Utiliza IA para identificar diferentes tipos de joias através da câmera
- **Interface Responsiva**: Design moderno com Bootstrap e tema dark
- **Controle de Câmera**: Toggle para ligar/desligar a câmera do dispositivo
- **Feedback Visual**: Indicadores de status e previsões em tempo real

### 🐍 Scripts Python

#### `debug.py` - Sistema de Faturamento
- Cálculo de subtotal de itens
- Aplicação de imposto fixo (10%)
- Sistema de desconto opcional por cupom percentual
- Exibição formatada da fatura

#### `num_primo.py` - Verificação de Números Primos
- Função otimizada para verificar se um número é primo
- Testes automatizados incluídos
- Interface interativa para usuário
- Documentação completa no estilo Google (em português)

#### `refatoracao.py` - Cálculo de Estatísticas
- Cálculo de soma, média, maior e menor valor de uma lista
- Validação de entrada com tratamento de erros
- Função reutilizável com type hints
- Exemplo de uso incluído

## 🚀 Como Usar

### Site Web
1. Acesse: [https://lucashx12.github.io/C-digo/](https://lucashx12.github.io/C-digo/)
2. Permita o acesso à câmera quando solicitado
3. Clique em "Iniciar Câmera" para começar o reconhecimento
4. Posicione uma joia diante da câmera para ver as previsões

### Scripts Python

#### Pré-requisitos
- Python 3.14 ou superior
- Navegador web moderno (para o site)

#### Executando os Scripts
```bash
# Navegue até a pasta dos scripts
cd test-assistent-programing

# Execute o script de faturamento
python debug.py

# Execute a verificação de primos
python num_primo.py

# Execute o cálculo de estatísticas
python refatoracao.py
```
